# What the emulator installs from its Dockerfile and does not declare in
# requirements.txt, plus the one library a test module uses directly.
#
# pyyaml is imported at module load by the CloudFormation provisioners;
# cryptography is what the KMS tests build real key material with.
#
# The Dockerfile installs both ("pyyaml>=6.0", "cryptography>=41.0") and no
# requirements file names them, so a client-side install of the tree does not
# get them. Hash-pinned like every other third-party install, so the suite runs
# against the tree the image carries instead of whatever the interpreter
# happens to have installed. cffi and pycparser are cryptography's own tree and
# must be pinned with it, because --require-hashes is all or nothing per file.
#
# The hashes are the x86_64 wheels an ubuntu-latest runner resolves: per-version
# wheels for pyyaml and cffi, an abi3 wheel for cryptography, and the universal
# wheel for pycparser.
