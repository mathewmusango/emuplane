# The Dockerfile installs pyyaml for the CloudFormation provisioners
# (ministack/services/cloudformation/provisioners.py imports it at module load),
# so an image carries it and a client-side install of the emulator's tree does
# not. Named here, and hash-pinned like every other third-party install, so the
# suite tests the tree the image carries instead of whatever the interpreter
# happens to have installed.
#
# The hashes are the manylinux x86_64 wheels for the three tested interpreters;
# the runners are ubuntu-latest, so a wheel is always the file pip selects.
